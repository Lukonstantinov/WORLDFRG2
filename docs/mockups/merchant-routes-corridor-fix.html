Merchant Routes — corridor snapping (straight-line slash fix)

The Merchant Routes overlay was the only line layer that drew a raw a→b straight line, ignoring terrain — exactly the red diagonal slashes reported. Every other line layer (flow highlight, house web, futures) snaps to the existing trade-route corridors via routeAlongTradeRoutes and skips when no corridor exists. This change brings merchant routes in line: cached path per route, stroked along roads/sea-lanes, no slash.

Implementation. OverlayManager.renderMerchantRoutes now strokes each route's cached path (built by routeMerchantRoutes(), which mirrors routeFuturesLanes() and re-runs only when the route set or the road network changes — never per frame). A route with no corridor path is skipped, never bridged with a straight line. Volume→width, the per-house colour, the land-leg dash and the cylindrical wrap-seam break are all preserved. If you still see a straight line on the futures layer it is the documented fallback in strokeLane when no corridor is found — say the word and I'll make that skip too.
