Coats of arms that never appeared — root cause & fix

CoatOfArms.tsx derives every house's shield from hash(name), an unsigned 32-bit value (h >>> 0). But feature selection used the signed shift h >> k. When a name's hash has the top bit set (~half of all names), JavaScript coerces h to a negative Int32 before shifting, so e.g. (h >> 3) % 5 is negative → SHIELD_SHAPES[-2] is undefined → the clip path's d is undefined → the whole shield is clipped away → blank arms. The fix: use the unsigned shift h >>> k everywhere.
