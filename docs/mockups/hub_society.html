What it does (and doesn't) do this iteration. The strata are a cheap statistical substrate: a city's composition is seeded from its trade orientation/wealth and evolves yearly via update_society (prosperity lifts families up the tiers; famine, dearth and disasters push them down toward the underclass). It gently tilts demand — patrician-heavy cities pull luxuries, commoner masses pull staples (society_demand_mult in base_need). It does not yet drive revolts or regime change — that is Iteration 3 (civil unrest), which will read this inequality/welfare substrate. Verified: society_shares_bounded + simulate_decades_reports_dynamics green (wealth bounded, shares ∈ [0,1], Σ=1, cities differentiate).
