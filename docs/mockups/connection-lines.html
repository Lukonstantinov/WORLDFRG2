The rule

RULE — EVERY line representing trade or a connection between settlements ALWAYS follows the existing trade-route network. No straight point-to-point segments. Every connection (corridors, dynamic flow, commodity trunks, house webs, futures lanes, merchant routes, and the new holdings lines) is snapped onto the already-computed least-cost roads (the coarse cost grid: mountain passes / rivers / coast-hugging) via routeAlongTradeRoutes. A line type only changes colour / width / style / direction — never the path. The bent sample lines below illustrate this.
Today: house webs & futures lanes already comply. Trade Corridors and Dynamic Flow still draw straight a→b lines (renderCorridors / flow redesign) and would be brought under the rule.
