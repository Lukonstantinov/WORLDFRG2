How it works

Generation (sim_generate_toponyms) reuses the deterministic culture-name engine (names.rs → cultures::place_name): each feature is named in the style of the people whose land it lies in. Rivers/lakes come from the Rivers step, peaks are prominent local elevation maxima, regions are the culture hearths' homeland names.

Gated & optional: the step button is disabled until Rivers (5) + Settlements (7) are done, and the backend errors if the culture map or rivers are missing — so you can't name a world before the things to name exist. Editable & persisted: rename any feature inline; save_toponyms writes the edited list to world metadata, so names travel with the world.
