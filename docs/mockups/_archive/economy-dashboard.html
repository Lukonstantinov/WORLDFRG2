How it works

Price Index (#30) is computed entirely on the frontend from the already-persisted economy snapshot: per city, a weighted mean of market.prices[g].price ÷ base_value across the goods basket (necessities weighted over luxuries via need_tier), scaled so 100 = world standard.

Inequality (#29) calls a new campaign_get_inequality read query — a pure read over the live sim's House.wealth_history (no tick.rs change). It returns the current Gini and top-10% share, a yearly Gini/concentration trend, house turnover (active / defunct / ever-founded), and a rank-churn mobility score.
