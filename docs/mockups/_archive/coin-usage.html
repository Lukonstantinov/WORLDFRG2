Coin usage — map overlay + per-coin breakdown

Select a coin → (1) the map tints every settlement that uses it (the mint city brightest, accepting/reserve cities shaded), and (2) the coin panel shows which settlements use it most as a donut or bar chart. Shares are by trade throughput settled in that coin; the chart refreshes once per year.
