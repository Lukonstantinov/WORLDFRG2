Each hub is a graduated disc: green where wine is cheap (near its vineyards), red where it is dear (cold northern cities far from the belt). Disc size grows with distance from par price.

How it works

Provenance (#35) filters economy.chains for the good (source→…→consumer with per-stop price) and, for manufactured goods, walks GoodSpec.inputs so you can click an input to trace it. History (#36) is a curated static card in commodityHistory.ts, also shown in the existing Good Detail sheet. Scarcity (#37) reads each hub's market.prices[good].price ÷ base_value and colours the hubs green→red, with a cheapest/dearest ranking. All offline, no campaign required.
