How it works

Backend command compute_itinerary(from, to, rivers, reach, desert_routes) reuses the existing coarse_dijkstra least-cost path and path_metrics medium-classification — no new pathfinding. Each leg is tagged land / navigable-river / sea; relief slows land legs and storm/reef hazard slows sea legs (same factors trade uses).

Per-mode days = land distance ÷ mode speed + water distance ÷ boat/ship speed. Land speeds: foot 25, horse 55, cart 18 km/day; rivers 40, ship 120 km/day (the map width = one Earth circumference, so 1 cell ≈ 40075 ÷ grid-width km). Ticking Avoid open-sea crossings sets reach = 2 so the route stays on one landmass (or reports unreachable).
