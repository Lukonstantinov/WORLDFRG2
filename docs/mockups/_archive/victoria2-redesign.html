WorldForge 2 → Victoria 2-style UI / UX redesign

A visual & interaction design proposal only — screens, layout, component library, map modes, colour & type tokens, and the flows that make the existing simulation feel like a grand-strategy game. No backend changes are designed here. Theme matches the app (bg #0b1420 · panel #13202e · text #cfe2f6 · accent #3a80c0).

4 · Map modes (reuse OverlayManager)

The grand-strategy feel comes largely from map modes — the same canvas recoloured. Each is a recolour pass on the existing OverlayManager visibility registry, so no new rendering pipeline is needed:

Political — country fill colours + borders
Population — density shading by province
Culture / religion — dominant-group tint
RGO / production — good icon per province
Militancy / unrest — heat from calm→boiling
Sphere / diplomacy — Great-Power influence

A map-mode strip (icons) sits where the layer selector is today; switching is instant and remembered per session.

Reusable components

  • Stat pill — value over caption (treasury, prestige, scores)
  • Budget slider — labelled track + knob; red/green/blue intent
  • Pop bar — name · proportional bar · percent (the population list)
  • Needs meter — life/everyday/luxury, good→warn→bad colour ramp
  • Reform row — status dot + label + unlock requirement
  • Ledger row — line item with signed coloured amount
  • Map-mode chip — icon toggle reusing overlay registry

These extend the existing panel style (HubPanel, HousesPanel, CoinCreditPanel) rather than introducing a new visual language.

6 · Interaction flows

Steering a country

Open Country screen → drag a budget slider → live ledger preview updates → confirm. Hover any number for a breakdown tooltip.

Inspecting a province

Click the map → right inspector slides in with pops, RGO, factories, militancy → click a pop bar to open its needs card.

Passing a reform

Politics tab → reform shows its requirement → when upper-house support crosses the line the row lights up → Enact, with a militancy-impact preview.

7 · Rollout — UI only, staged on the existing screens

1
HUD shell. Country top-bar + tab drawer + full-bleed map skin, toggled by "Play this world". No new data — reads existing campaign snapshot.
2
Map-mode strip. Political / population / militancy / production recolours on OverlayManager.
3
Population & pop cards. Render Society strata as pop bars + needs meters in the inspector.
4
Budget & Politics tabs. Sliders + reform rows wired to existing polis policy / CityFinance.
5
Diplomacy & Great-Power bar. Scoreboard + relations view over existing war/economy data.

8 · Verdict

A Victoria 2 look & feel is achievable as a pure UI/UX layer.

Every screen above is driven by data the campaign sim already produces (society strata, treasury/tariff, wars, prestige-like scores, market prices). The redesign is new chrome over one unchanged canvas: a country HUD, eight tabs, map modes, and a small component kit built in the app's existing dark theme.

Claude can design and build this UI incrementally (steps 1→5), each a self-contained front-end change with its own HTML report. The live Tauri window still needs your machine to view; verification here is via these mockups and the type-checks. Deeper Victoria mechanics (real POP objects, tech tree, full diplomacy) are a separate systems track — out of scope for this UI-only proposal.
