Futures overlay — corridor-only lanes

Issue: futures contract lanes sometimes drew a straight diagonal directly between two cities, ignoring the road/sea network. Colours below are the real termColor() gold gradient from OverlayManager.renderFutures; the coastline + road network are schematic.

Before — straight slash fallback

━ ━ futures lane jumps the chord, crossing the mountain band and a bay it could never traverse. The road network (tan) is ignored.

After — corridor only (or skipped)

The lane now follows the snapped corridor (roads/sea-lanes, via routeAlongTradeRoutes). If no path can be snapped, the lane is skipped entirely — no slash, no orphan square/ring markers — matching the merchant-route layer.

Code: renderFutures's strokeLane no longer falls back to [r.a, r.b]; it returns false for a path-less lane, and the draw loop now continues on !(r.path && r.path.length >= 2) before drawing any markers. The trade-route graph must be loaded for lanes to snap; if the Trade Routes layer data isn't present, lanes are hidden rather than drawn straight.
