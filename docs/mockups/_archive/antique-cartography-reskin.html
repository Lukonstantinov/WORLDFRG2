Antique cartography reskin — goods · settlements · routes

An art-direction proposal: keep all the existing vector drawing (no image assets, no new pipeline) but re-skin the three things the eye reads on the map into an authentic old-map / engraving look — parchment wax-seal good medallions, pictorial town glyphs, and sepia rhumb-line routes. Every panel below is drawn live on canvas, current style vs proposed, using the same primitives the app already ships.

1 · Good icons — wax-seal engravings

Now glossy medallion
Proposed parchment seal · engraved

Same silhouettes (the existing SYMBOLS table in goodIcons.ts is kept) — only drawGoodIcon's disc is re-skinned: parchment fill, cross-hatch shading, an irregular hand-inked rim and a wax-stamp symbol instead of the gradient + gold ring. One function changes; all 90 goods inherit the new look.

2 · Settlements — pictorial map glyphs

Now coloured dots
Proposed drawn towns

Tier reads from the shape, like a Renaissance map: village = a single gabled hut · town = a clustered roofline · city = a walled enclosure with towers · capital = walled city with a banner keep · outpost = a lone watchtower. Population still scales the glyph; a faded-vermilion roof keeps them readable on land and sea.

3 · Routes & the sea — rhumb lines and a compass

Now bright lanes
Proposed sepia rhumb lines

Routes become cartographic ink: overland caravan tracks are dotted sepia, sea lanes are fine verdigris rhumb lines with periodic ship ticks, major trunks are a hand-inked double line. A compass rose and faint lat/long graticule sell the "old chart" feel. These are line-style + colour changes in LINE_COLOR_DEFAULTS and the trunk/route renderers — no routing logic touched.

5 · Verdict

The whole "authentic old map" feel is reachable as a reskin of three vector draws — good medallions, settlement markers, and route lines — plus a compass/graticule flourish. No new art assets, no new rendering pipeline, no simulation changes. The biggest single upgrade is the settlement glyphs (dots → drawn towns); the cheapest is the route palette.

A full parchment paper base map (aged land/sea tones, torn-edge vignette) is a worthwhile follow-up but is a server-side tile-render change — proposed separately so the cheap, high-impact reskin can ship first. I can implement these incrementally, each with its own before/after report.
